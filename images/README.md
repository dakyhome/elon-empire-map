# Bubble header images

These are the cinematic header images shown behind the title when a bubble's
detail panel opens (Spotify-style). One image per node, named by the node's
**id** (the first column in the data CSV).

## Naming rule

Save each file as `images/<id>.jpg` (PNG or WebP also work — the page tries
`.jpg`, then `.png`, then `.webp`). If a bubble has no image file, the panel
just keeps its current solid-colour header. Nothing breaks. So you can add
images gradually.

## What to look for

- **Wide / landscape** shots (the header is wide and short, ~3:1 crop).
- **High-res** (≥ 1200px wide) so it stays crisp.
- **Simple composition** with a clear subject and some calm/dark area — the
  title and stat chips overlay the **lower-left**, so avoid important detail
  jammed into the bottom of the frame.
- **Dramatic / cinematic** mood. A dark or darker-toned lower half reads best.
- **Consistent feel** across all 23 so the map looks cohesive (e.g. all
  moody/dramatic rather than mixing bright studio white with night shots).
- **Avoid:** existing text/watermarks/logos, collages, portrait crops,
  cluttered scenes, low-res thumbnails.
